### 1. 動き方の不具合（三つ見つけて直した）

`npm run stuckmap` と、足止めされた大ネズミの一歩ずつの動きを追って突き止めた。

1. **止まっている仲間の後ろで動けなくなっていた**：列の間合い（同じ群れの仲間がすぐ前にいれば歩みをゆるめる。細い通路で一列になっても重ならないため）が、前の仲間が休んでいる・食べている・眠っているときにも働き、歩みが15％に落ち続けた。そこにやわらかい間合いが押し返すので、広い床でも先へ進めなかった。前の仲間が動いているときだけゆるめ、止まっているなら脇へよけて追い越すようにした。
2. **火と目当ての間を行ったり来たりしていた**：正面の入口のかがり火（怖さの届く半径4マス）のそばに巣穴があると、巣穴へ帰ろうとしては火に追い返され、一刻みごとに行ったり来たりしていた。巣穴は火のそばに作らず（新しく作るときも、移るときも）、火に追い返された大ネズミは、火のそばの目当てをあきらめる。巣穴そのものが火のそばなら群れで移る。
3. **届かない巣穴へ帰ろうとしていた**：巣穴が引っ越したり遠くまで餌を探しに出たりして、道筋の見つからない巣穴へまっすぐ歩いては壁に当たり続けていた。巣穴への道筋が見つからなければ、はぐれ者になって食べ物を探し、近くの巣穴に加わる。

seed7 の12日で確かめると、大ネズミの飢え死にが 145 → 14、足止めの回数が 9,012 → 3,033 になった。

### 2. 殖える数を巣穴のまわりで決める

巣穴ごとに、まわり（10マス）の食べられる苔で養える数（`Burrow.cap`）を、ダンジョン全体の苔と同じ決まった刻みで数え直して保存し、巣穴の住民がそれを超えるなら子を産まないようにした。

- 最初は「いまある苔を、一匹が地上の2日に食べる量で割る」（全体の目安と同じ割り方）にしたが、巣穴ごとに2〜5匹にしかならず、中で生まれた数が 2,013 → 70 に落ち、ダンジョン全体で数匹しかいなくなった（苔はそのあいだにも育つのに、いまある量だけで数えたため）。「一匹が地上の1日に食べる量で割る」に直した（中で生まれた 557）。

### 効いていないこと

- **近くに苔があるのに飢える割合は、ほとんど変わっていない（59％ → 56％）**：飢え死にの数は4分の1になったが、残った飢え死にの半分は、まだ近くに苔があるところで起きている。いちばん多いのは、苔を目指して歩いている途中（st 1）。今回直した三つのほかにも、足止めの原因が残っている（`npm run stuckmap` で、群れで出ていく途中の大ネズミが通路の角で止まる例が見えている。まだ追えていない）。
- **外から来る数が増えた（894 → 1,500）**：中で殖えにくくなったぶん、ダンジョン全体の苔で決める「来る数」の条件が空きを埋めている。来ては出ていく（群れで出ていった 490）出入りが多い。来る数も、巣穴のまわりや口のまわりで決めるかどうかを相談したい。

## コボルトが来るかどうかを口のまわりで決める

地上の約2時間（600刻み）ごとに決まった刻みで、開いた地表の横穴ごとに「歩いて行ける範囲に、住処の条件を満たし、まわり8マスの食べ物（食べられる苔とキノコ＋ネズミ1匹100）が1,500以上ある場所」があるかを調べて保存する（`kobMouthOk`）。住処がまだないとき、そういう場所のない口からはコボルトが来ない。住処を移すとき、分かれるときも、同じ条件の場所を選ぶ。

- 来たコボルトの合計：537（直前）→ 250。中で生まれた：110 → 92。
- **seed6 に効いていない理由（見立て）**：seed6 は、口の判定を通った（横穴から歩いて行ける範囲に、住処の条件を満たし食べ物も1,500以上ある場所があった）ので来ている。ただ、豊かさ（横穴から行ける範囲全体の平均）は8シードでいちばん低く、来たあとは襲われて捨てる（3回）ことで終わっている。食べ物の足りる場所が一か所あることと、群れが続くことは別で、続かない理由は食べ物ではなく襲われることのほうだと見ている（確かめてはいない）。「乏しいシード」を豊かさの平均で判断して来る数を絞るなら、口の判定とは別の決め方が要る。

**畑のキノコを外しても、来たゴブリンの数は変わらなかった（両方とも200で、展開もまったく同じ）**。調べると、ダンジョンのキノコは6日目以降 5,000〜27,000 あり、条件の 3,000 をいつも大きく超えている。コボルトの畑のキノコは数百で、条件を左右していなかった。前回ゴブリンが増えていたのは、畑ではなく、もう一つの条件「大ネズミが8匹以上」のほうが満たされやすかったためと見ている。今回は大ネズミの数が殖えすぎなくなったので、ゴブリンの来る数が 615 → 200 に減った。数え方の変更（畑の外のキノコだけ）は残した。
