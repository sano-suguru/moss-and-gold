16のシードを25日ずつ、冒険者の一行の上限1で回し、**いまの main（PR #2 のマージ後、a5441c8）**と対にして比べた（`npm run ab -- --preset final --base main`）。住みつける仕組みはこの七巡目で一区切りにする。

- 対にした比較の全体（シードごとの数字つき）：docs/compare-20261109.md（main → 七巡目の最終）
- 変更ごとの段階を並べた表：docs/compare-20261109-steps.md（main、(1)、(1)+(2)、(1)〜(3)、(1)〜(4)、最終）

良し悪しは「はっきり／ばらつきの内」の目安（docs/rework-tools.md）で判断した。「はっきり」は、差の90％区間が0をまたがず、符号検定 p<0.1、いちばん効いた1シードを除いても向きが変わらないもの。

  - **main からあった不具合を一つ直した**：abc を7日目で分けて回すと、8.5日目から展開が分かれていた（main でも同じ）。湿り気 `moist` は保存せず40刻みごとに作り直すが、床でなくなったマスに前の値が残り、読み込み直したとき（0から作る）と違っていた。スライムは湿った隣のマスへ這うときにこの値を見るので、そこから分かれた。作り直すたびに全体を0にしてから床を埋めるようにした（src/world.ts の `computeMoist`）。展開がわずかに変わるので、最終の比較はこの直しを入れて回し直した。

## 結果（main → 七巡目、16シード×25日）

### 大ネズミ

| | main | 七巡目 | 目安 |
|---|---:|---:|---|
| 絶えたシード（最後の2回の記録で0） | 1（seed6） | **0** | ばらつきの内（1シードだけの差） |
| 0匹だった日数（5日目より後、16シードの合計） | 78日 | **7.8日** | **↓ はっきり**（10シードで減、増えたのは2） |

まず main で、まだ絶えるシードがあるかを確かめた：seed6 は最後に0匹（5日目より後の81記録のうち66で0匹）、abc は9.75日続けて0匹、seed7・seed17・seed18 も数日ずつ0匹が続いていた。七巡目では、0匹の日数は78日 → 7.8日になった。

飢え死には増えたが、生きている大ネズミの数（最後の数 138 → 226、中で生まれた 974 → 1,558）が増えたぶん。

一方、**縄張りは長くならなかった**（中央値0.8日、平均は約1日のまま）。縄張りの終わり方を数えると、いまは飢えより、冒険者に倒される（(4) の段階で80匹）と竜に焼かれる（36匹）ほうが多い。飢えて去るのは89匹で、main の251匹から減った。縄張りを長く続けるには、冒険者と竜との関係を見直す必要がある。冒険者の作り直しのときに一緒に考えたい。

**(4) を足した理由**（docs/compare-20261109-steps.md）：(2) だけでは、オークが腹を空かせるたびに取り立てに来るので、集落の蓄え（シードごとの平均の中央値）が 233 → 61 に減った。5日以上続いた集落の割合も 22.2％ → 6.7％、ゴブリンの絶えたシードも 1 → 4 に悪くなった（どれも「ばらつきの内」だが、向きがそろっていた）。(4) で集落の取り分を残すと、蓄え 105、5日以上 14.6％、絶えたシード 4（(3) のあとは6）に戻り、オークの飢えて去った数は 89 のまま低かった。

## ウィスプの動き（PR #2 の間引きの見た目）

- **数で**：描画と同じ式（`moveAlpha` と main.ts の `alpha`）で、abc の1.5〜1.6日目の2,000刻みを1刻み8こまに分け、こま間の動きの大きさを測った。ウィスプは中央値 0.018 画素、最大 0.038 画素（最大÷中央 2.1）。止まるこまはなかった。大ネズミ（間引きなし）は最大÷中央 1.1。4回に1回の判断の切れ目で位置が跳ぶことはない。向きが変わるのは0.8秒（1×）に1回だが、速さをなめらかに変える式（0.86 の減衰）なので、角は目立たない。
- **ゲームの画面で**：dist/index.html を Playwright（ソフトウェア描画、毎秒約41回描く）で、ウィスプのまわりを速さ1×で流し、0.15秒ごとに切り出して並べた（docs/img/wisp-filmstrip.png、4倍の拡大をさらに3倍）。光の玉は、こまごとに少しずつ同じ向きへ漂っていて、跳びやかくつきは見えなかった。
- ただし、これはソフトウェア描画での確かめ。実機のブラウザ（とくに描く回数が刻みと合わない60Hz以外の画面）での見え方は、次の画面確認のときに目で見てほしい。

## 次に考えること

- ゴブリンの集落の日数は、いまは飢えより冒険者に左右されている。オークも、縄張りが短いのは冒険者と竜のため。冒険者の作り直し（見える目的、依頼など）で、どの集落をどれだけ狙うかを決めるのがよさそう。
- 大ネズミの飢え死には、数が増えたぶん増えた。`ratFoodCap` / `Burrow.cap` は今回は触っていない。
