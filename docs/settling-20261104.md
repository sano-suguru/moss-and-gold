## 入れたもの

- 冒険者の一行の上限の既定を1にした（`Ecology.ADV_MAX_PARTIES`、`--adv-max` で切り替えられる）。
- コボルト
  - 自然の口から4〜6匹の群れで来る（あとから加わる者は2匹ずつ）。
  - 「2匹を切る」は、もともと「1匹になる」と同じ判定だった（2匹未満＝1匹）。そこで緩め方として、1匹になっても地上の1日は新しく来る仲間を待ち（来る者はいちばん小さな住処に加わる）、それでも1匹なら捨てる、にした。今回「1匹になって」捨てた住処は0。
  - 掘った横穴の中と入口から2マスは、キノコの畑の判定で「地中の湿り気がある」扱いにした（湿り気の値は書き換えない）。畑のキノコは土の養分から作るので、養分の帳簿は保たれる。
  - 子を産むのは蓄えが目安の3割以上のとき（前は半分）。
  - 住む場所を選ぶとき、口からその場所までの道筋で人の気配の濃いマスを数え、多いほど点を下げる。
  - 口から住処へ向かう道中（新しい状態 st 11）は、冒険者が8マス以内にいる間、その場で身をひそめて待つ（st 12。隠れている住処と同じく、すぐそばまで来られない限り気づかれず、描かれない）。10マスより離れたら進む。
- 大ネズミ
  - 巣穴の引っ越し：巣穴のまわり（10マス）の食べられる苔が一匹あたり150に満たなくなったら、歩いて行ける（道のり120マスまで）苔の豊かな所へ群れごと巣穴を移す（地上の1/4日に一度まで試す）。腹を空かせたネズミが外へ出ていく前にも、まず引っ越しを試す。記録に「大ネズミの群れが…巣穴を移した」、分析用に stats.moves（sim の moves.jsonl）を足した。
  - 外へ出ていく条件を「開いた地表の横穴まで歩いて行ける」に広げた。ただし道のりは、飢え死にする前に着ける長さまで（残りの辛抱の8割で歩ける距離、最大150マス）。

## 測りながら直したこと

- **道筋の気配で候補を外すと、住処が作れないシードが出た**：最初は「道筋に気配の濃いマスが9以上あれば選ばない」にしたが、口が入口のそばにあるシード（seed5、seed8）では、どの候補も外れてコボルトが一匹も来なくなった。外すのはやめ、点を下げるだけにした。
- **遠い口へ向かったネズミが道中で飢えた**：「歩いて行ける」を道のり150マスにすると、遠い口へ向かう途中で飢えるネズミが多く出た。着ける長さまでに絞り、道すがら苔を食べられるようにし、飢えが7割まで進んだら出ていくのをやめて近くで探すようにした。
- **増水した水に取り残された大ネズミが動けずに飢えていた**（不具合）：大ネズミは深い水（40より深い）に入らないが、立っているマスの水かさが増すと、まわりも深くて一歩も動けなくなっていた。深い水に取り残されたネズミは、泳いで抜け出せるようにした。seed7 の飢え死にが、これだけで約半分になった。

## 効いていないこと（次の相談のために）

### コボルトの住処

- 終わり方はほとんど「蓄えが尽きた」（18）。1匹になって捨てた住処は0になり、襲われて捨てたのは6。
- 続くシード（abc 10.8日、かしたれ 6.5日）と続かないシード（はじまりの洞窟 1.0日、seed8 1.5日、seed6 1.4日）がはっきり分かれる。続かないシードは、住処のまわりに食べ物（ネズミ、苔）が乏しく、横穴の畑だけでは群れを養えていないと見ている。キノコの畑は1回に最大6、3マスまでなので、群れが大きくなると足りない。畑の広さや育つ速さ、住む場所の選び方での食べ物の重みを、次に相談したい。
- 中で生まれた数は124に増えたが、来た数（521）に比べるとまだ少ない。
- 冒険者に倒された数が76から115に増えた。来た数が420から521に増え、住処が長く続いて冒険者と出会う機会も増えたためと見ている。

### 大ネズミの飢え死に（852、−51％）

- 巣穴の引っ越しは126回起きたが、飢え死には減らなかった。中で生まれた数が1,041から1,618に増えている。引っ越して食べ物の豊かな所へ移ると、よく殖えて、また飢える。
- 飢え死にしたネズミを追うと、多くは巣穴のまわりに苔が十分ある所で、苔を目指して歩いている最中に飢えている。狭い通路で前に進めず、5〜10マス先の苔にたどり着けないうちに時間切れになる様子が見えた（道筋の行き詰まりの回数が多い）。群れが狭い所に集まったときの動き方（すれ違い、押し合い）の問題で、来る数や巣穴の場所では直らない。次は動き方を見る必要がある。
- 殖える数は「ダンジョン全体の食べられる苔」で抑えている。引っ越した先で殖えすぎることへの手当て（巣穴ごとに養える数で抑える）も候補。

### ゴブリンとオーク

- ゴブリンの来た数が445から625に、オークが380から402に増えた。ゴブリンは「キノコが3,000を超え、ネズミが8匹以上」で来るので、コボルトのキノコの畑でダンジョンのキノコが増えたことが効いていると見ている。オークは「ゴブリンかコボルトの集落がある」と来る。

## 見た目の確認（スクショ）

撮り方：`tools/gallery/koboldshots.ts` で場面を作り（かしたれ。住処は3.9日目、隠れている住処は14.6日目。霧で隠れないよう、見たマスは地図全体にした）、`tools/gallery/koboldshots.mjs`（Node の Playwright）で `dist/index.html#clean` を撮った。`-marked.png` は、入口・横穴の奥・罠・畑のキノコ・隠れている者の位置に枠と名前を重ねた写し。

- docs/img/kobold-den.png / kobold-den-marked.png：住処（横穴・罠・キノコの畑）
- docs/img/kobold-hide.png / kobold-hide-marked.png：隠れている住処

気になった所：

1. **罠の印がほとんど見えない**：罠は青い小さな点（1〜2画素）で、4倍に拡大しても印をつけた写しでやっと分かる程度。暗い床に紛れる。
2. **罠が横穴の中に置かれる**：「入口から2〜3マスの床」は横穴の中も含むので、罠は横穴の通路に並ぶ（入口の外ではなく）。冒険者が横穴に踏み込んだときにだけ働く。意図どおりかどうか確かめたい。
3. **横穴は見分けにくい**：掘ったマスは砂利のような床として描かれ、まわりの岩とは区別できるが、住処のある所はたいてい暗く（光の筋から離れた所を選ぶので）、全体が沈んで見える。住処の目印（入口の飾り、巣材など）はない。
4. **キノコの畑は見えるが控えめ**：育ったキノコは紫の小さな光の点として見える。この場面では、畑は横穴の中ではなく、横穴の脇の開いた床（湿り気の足りる所）にできていた。「畑らしさ」（並んだキノコ、耕した土）はない。
5. **隠れている者は描かれないので、隠れていること自体が分からない**：住処の奥には何も描かれず、見る人には「誰もいない」ように見える。気配の手がかり（暗がりの目の光など）を出すかどうか相談したい。
6. 横穴の上にある「I」の形は、眠っているコボルトの眠りの印（Z）だった。

## 見た目の改善（このあとに入れたもの）

上の「気になった所」を受けて直した。スクショは docs/img/kobold-den.png、kobold-hide.png（と -marked.png）を撮り直した。

1. **罠**：錆びた鉄の板に白い歯が並ぶ絵にした（15×7画素。歯の先は光をはじくので、暗い床でも見える）。前の青い点は1〜2画素だった。
2. **罠の置き場所**：横穴の中（掘ったマス）には置かず、入口の外の床（入口から2〜3マス）に置くようにした。シミュレーションの変更なので、罠を踏む回数は変わりうる（かしたれ20日では0回。8シードでは測り直していない）。
3. **横穴の目印**：入口の脇（横穴と反対の側）に、しゃれこうべと赤い布を下げた木の杭を立てる。横穴の奥（住処の中心）には、わらと毛皮の寝床を描く。暗い所では青みがかって見えるが、形で分かる。
4. **キノコの畑**：畑のマス（住処のそばの決まった3マスまで。シミュレーションと同じ `farmTiles` で決まる）に、耕した畝と植えたキノコの列を描く。キノコが育つ（80以上）と、ふちがほのかに光る傘になる。
5. **隠れている者**：姿は描かず、暗がりで光る二つの目だけを描く（ときどきまばたきする）。道中で身をひそめて待っている群れも同じ。

どれも描画だけで、保存する状態は増やしていない。決定性と四つの帳簿は保たれている（`npm test` 21項目 OK、かしたれ20日で帳簿のずれ0）。
