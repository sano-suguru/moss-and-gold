## 効いたこと

1. **一匹ずつ去っていた本当の理由**：`leaveIfStarving` は「最後に食べてからの刻み」（`sinceMeal`）だけで判断していた。コボルトは腹が減るまで食べないので、来たときの食べ物を抱えたまま地上の1/4日で「飢えて去って」いた。住処を持つコボルトはこれをやめ、群れの出来事（蓄えが尽きて1日、何度も襲われた、2匹を切った、竜が来た）にした。
2. **冒険者に倒されなくなった**：効いた順に、(a) 冒険者に気づいたら（8マス）戦わずに逃げる、(b) 冒険者が逃げていく弱い者を追わない・射かけない、(c) 追っ手がすぐそばにいるあいだは住処へ向かわず追っ手から離れる（以前は、住処へ逃げ帰る途中で冒険者の脇を通って倒されていた）、(d) 仲間が襲われても、ずっと強い相手には加勢しない、(e) 奥に隠れる。罠を踏んだ記録は25日で4〜10回（同じ種類の記録は間を空けて残すので、実際はもっと多い）、隠れているところを見つかったのは4〜14回。
3. **ドラゴンの火**：住処を竜から離す、若い竜にも隠れる、竜の寝床のそばの口から入ってこない。abc では寝床が横穴のすぐ脇にあり、そこから入ってきたコボルトが一匹ずつ幼竜にかまれていた。
4. **大ネズミ**：来る数・殖える数を食べられる苔に合わせたこと、群れで出ていくこと、それに食べ方の不具合を三つ直したことが効いた（下の「ついでに直したもの」）。

## 効いていないこと（次の相談のために）

### コボルトの住処が5日続かない

住処の日数は二つの山に分かれている。うまくいった住処は10〜20日続く（上限2で13.2日、上限1で19.5日）が、多くは1〜2日で終わる。終わり方（上限2の25日、8シード分）：

- 蓄えが尽きて捨てた：25
- 2匹を切って捨てた：14
- 何度も襲われて捨てた：4

効いていない理由として見えていること：

1. **食べ物が足りない場所が多い**：蓄えが目安の半分に届くことがまれで、子が生まれない（中で生まれたのは8シードで66。前は916）。群れは「来た3匹＋あとから加わる2匹ずつ」のままで、数の中央値は8前後。キノコの畑は、暗く湿った床（湿り気40以上）が住処のそばにないと育たない。畑ができる場所を選ぶ条件を住む場所の選び方に入れるか、狩り（ネズミ）の比重を上げるか、相談したい。
2. **来た口から住処までが遠い**：住む場所は人の気配の薄い所（入口から30マス以上）を選ぶので、口が入口の近くにあるシードでは、来た群れが冒険者の多い所を40マス以上歩いて住処へ向かい、途中で倒れたり散ったりする。「2匹を切って捨てた」の多くはこれ。
3. **小さな群れはすぐ「2匹を切る」**：3匹で始まるので、1匹倒れて、さらに1匹欠けると捨てる。2匹を切ったときの扱い（近くの住処に合流する、残った1匹は加わる者を待つ、など）を決めたい。
4. **冒険者が多いと（上限4）悪くなる**：冒険者に倒された数は305、住処は1.5日。冒険者の数そのものが住処の続き方を大きく左右している。上限1では倒された数76、住処2.5日で、コボルトの目安はどれもいちばん良い。

### 大ネズミの飢え死にが7割減らない（5割前後）

- 来た数は2,554 → 1,114、中で生まれた数は1,512 → 1,199 に減った。それでも飢え死には893。
- 飢え死にしたネズミのほとんどは、すぐ近く（道のりで10マス以内）に食べられる苔がある所で死んでいる（かしたれで調べると158匹のうち約100匹）。ダンジョン全体の苔の量では足りているのに、巣穴のまわりでは足りていない。全体の量で来る数を決めているので、局所の不足が見えていない。
- 群れで出ていく条件の「開いた地表の横穴が30マス以内」に当てはまる巣穴が少ないシードがある（かしたれ、はじまりの洞窟、seed8 は出ていった数が0〜24）。
- 次の候補：巣穴を苔の近くに作り直す（今は横穴のそば）、巣穴ごとに養える数で殖える数を抑える、口までの距離の目安を広げる。

### ほかの種への影響

- ゴブリンの来た数が516 → 731、オークが267 → 390 に増えた。オークは「ゴブリンかコボルトの集落があると来る」ので、住処が長く残るぶん来やすくなった。ゴブリンも同じ口から来るので、コボルトとの取り合いが減ったぶん来やすくなったと見ている。
- 冒険者の死者（261 → 256）、生還（1,519 → 1,439）はほぼ同じ。ドワーフの死者は70 → 38。

## ついでに直したもの

- スケルトンが崩れて消えるときに、死として記録されていなかった（死因 crumbled を加えた）。
- 大ネズミの食べ方の不具合（飢え死にに大きく効いていた）：
  - 腹を空かせていても、豊かな群落（量が距離×4＋36以上）しか目当てにしなかった。近くの薄い群落を素通りして、間に合わない遠くの群落へ向かい、苔の上で飢えていた。腹を空かせた大ネズミとコボルトは、薄くても近い群落を選ぶようにした。
  - 遠くの目当てに道筋が通らないまま、足もとの苔を食べずに飢えていた。足もとに食べられる苔があればそこで食べる。
  - ひどく腹が減っても目を覚まさず、眠ったまま飢えていた（大ネズミとコボルトだけ、飢えると目を覚ます）。
- コボルトの「逃げ帰る先」が、来たときの口のままだった（住処へ逃げずに口へ戻り、口のそばの幼竜に倒されていた）。
- コボルトの道筋を探す広さが6,000マスまでで、遠い住処へたどり着けずに口のそばに留まっていた。住む場所を「歩いて行ける所」から選ぶようにし、探す広さを大ネズミと同じ15,000マスにした（群れで去るときは地図全体）。
