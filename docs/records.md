# 実行ログの形式（runs/<名前>/）

`npm run sim` / `batch` / `ab` が書き出すファイル。どのファイルも、`t` は tick、`k` は種の番号（`src/names.ts`）、`x, y` は px 単位の位置。出力の内容を変えたら、このページと tools/analysis/sim.ts をあわせて直す。

| ファイル | 中身 |
|---|---|
| settle.jsonl | `{t, k, id, ev, how, reason, to, n, x, y}`。定住する群れの出来事（k 10 コボルトの住処、k 12 ゴブリンの集落）。ev は found（住みついた。how：arrive 外から来た（古い実行結果） / soil 土の養分から湧いた群れが住みついた / move 引っ越した / split 分かれた。poor が 1 なら、食べ物の足りる場所が無く、貧しい場所に少ない群れで住みついた）、abandon（捨てた。reason：food 食べ物が尽きた / raids 襲われすぎた / alone 1匹になった / dragon 竜が近くに来た。to：leave 外へ去った / move 中で移った）、empty（誰もいなくなった）。ほかに、ev が unbury の行は、壁や瓦礫のマスの中に埋まっていた生き物（k は種、id は個体）が、安全策でいちばん近い床へ出た記録（x, y は出た先）。k 25（冒険者の一行。id は一行）の ev が wake の行は、焚き火で眠る一行が起こされた記録（how：watch 見張りが気づいた / thief 眠りの浅い盗賊が気づいた / hit 寝ている者が打たれた / noise 物音。n は気づいた相手の種、doze は見張りがうとうとしていたか、night は夜か）、nightHit は眠っている者への寝込みの一打ち（n は打った種）、campBreak は夜襲の被害（how：lost 倒れた者が出た / hurt 深手）で焚き火を消して発った記録（src/eco/night.ts）。k 4（クモ。id は巣）の ev が web の行は、クモの巣の出来事（how：catch 大ネズミかアリが捕まった / tear 大きな者が引き裂いた / cut 冒険者が切り払った。by は捕まった・裂いた者の種。src/eco/spider.ts）。k 29（リビングアーマー。id は個体）の ev が absorb の行は、武器か盾を取り込んだ記録（how：floor 床の物 / rob 倒した相手の落とし物、n は武具の種類 ItemKind）、fall は崩れて武具が床に散らばった記録（n は散らばった武具の数。src/eco/armor.ts）。k 12（ゴブリン。id は集落）の ev が cacheGo の行は、蓄えの乏しい集落から冒険者の物資の置き場へ食料を取りに出た記録（n は出た数、to は置き場、how は集落から歩いてのマス数）、cacheLoot は置き場の木箱をあさって袋に詰めた記録（n は詰めた量、how は置き場に残った量。src/eco/cache.ts）。k 15（ミノタウロス。id は個体）の ev が drag の行は、仕留めた獲物の死骸を寝床まで引きずり終えた記録（n は獲物の種、x, y は寝床に着いた所。src/eco/monsters.ts）。k 19（ヴァンパイア。id は個体）の行は、scout（従うコウモリが獲物の上を旋回しはじめた。n は獲物の種）、pin（コウモリに群がられて足止めされた獲物に打ちかかった。n は獲物の種）、scatter（コウモリの群れにばらけて逃げた）、reform（ばらけた群れが姿を戻した）、coffinOpened（僧侶か竜殺しに棺を暴かれた。n は職業）、lightKill（光の中でばらけられずに倒された。n は倒した種）、callBats（日暮れにコウモリを呼び寄せた。n は呼んだ数）、raiseFallen（倒れた冒険者の亡骸にかがみ込み、眷属になる印を付けた。n は職業）（src/eco/vampire.ts）。ev が joined の行は、入口側と切り離されていた住みか（k 10 コボルトの住処、12 ゴブリン・14 リザードマンの集落、9 アリの巣。id は住みか）が、入口側の洞窟とつながった記録（how：1 住処のコボルトが内側から掘ってつないだ / 0 それ以外。瓦礫の風化、ほかの者の掘削など。src/eco/islands.ts の markJoined）。k 5（スライム。id は分かれる前の個体）の ev が split の行は、死骸を食べて育ったスライムが二つに分かれた記録（n は分かれて生まれた個体。src/eco/slime.ts）。ev が burn の行は、炎に焼かれた記録（k は火をつけた種で、いまはドラゴンだけ。id は焼かれた個体、n はその種。前に傷を受けてから生き物の更新100回より後の、最初の一回だけ。src/eco/fire.ts）。ev が gen の行は、魔物が土の養分かマナから湧いた記録（群れごとに1回。k は種、how：nutr 土の養分から / mana マナから、n は湧いた数、x, y は場所。src/eco/generate.ts）。ev が starveBlock の行は、湧く種が飢え死にした区画のそばで、飢え死にの記憶のために、その回は湧かなかった記録（k は種、n はまわり9区画の記憶の合計、x, y は湧くはずだった場所。src/eco/generate.ts の starveBlocks）。ev が manaLow の行は、マナで命をつないでいた大物（トロール・バジリスク・ミノタウロス・ガーゴイル・ヴァンパイア。id は個体）のマナが尽きかけた記録（src/eco/step.ts の metabolism）。k 25 の ev が heroMana の行は、冒険者が倒れた所でマナが立ちのぼった記録（id は倒れた冒険者、n は生まれたマナの量） |
| samples.jsonl | ゲーム内の1/4日ごとのサンプル。シードの豊かさ（rich：開いた地表の横穴から歩いて100タイル以内の床1タイルあたりの、食べられる苔とキノコの量）、種ごとの数（`counts`、キーは種の番号）、死骸、開いた床、瓦礫、使える養分とその総量、保存則のずれ（nutrientDrift / goldDrift / rockDrift）、噂、冒険者パーティの数、外の世界の地図の区画数、ドワーフの拠点の発展段階 |
| deaths.jsonl | `{t, id, k, cause, by, x, y, slain?, near?, camp?}`。id は死んだ個体の番号（settle の burn と照らし合わせる。古い実行結果には無い）。camp は、焚き火で休む一行の冒険者だった（1）。slain は、cause が eaten のとき、打ち合いで仕留めてから食べた（1）。無ければ一口で食べた（クモの巣・ワーム・空中でさらう・ミミック・死骸）。cause は死因：eaten 食べられた / fight 戦って倒れた / starve 飢え / burned 焼死 / crushed 崩落 / petrified 石化（by はバジリスクの睨みなら 17、トロールが光の筋を浴びたなら −1）/ killed 襲われた（ゾンビなど）/ dried 干からびた（スライム）/ faded ゴーストが消えた・リビングアーマーのマナが尽きた / planted マイコニドがキノコになった / crumbled スケルトンが崩れた / crumble 眷属が崩れた / sipped ウィスプがマナの減った大物に吸われた（by は吸った種）/ other。by は手を下した種（なければ −1）。near は飢え死にした大ネズミについてだけ、食べられる苔・キノコまでの歩いての距離（60タイルまで、なければ −1） |
| births.jsonl | `{t, k, origin, x, y, from?}`。origin は出現の経路：entrance 正面の入口 / mouth 地表の横穴 / fissure 地底の裂け目 / river 川の出口 / shaft 天井の裂け目 / soil 土の養分から湧いた / mana マナから湧いた / gear 床の武具から生まれた（リビングアーマー）/ raised 亡骸が起き上がった（ゾンビ・スケルトン・眷属。from は亡骸の種）/ born ダンジョンの中で生まれた（親から、卵から） |
| moves.jsonl | `{t, k, n, x, y, tx, ty}`。大ネズミの巣穴の引っ越し：n 匹が、元の場所（x, y）から移った先（tx, ty）へ |
| exits.jsonl | `{t, k, reason}`。ダンジョンから外へ出ていった理由：starving 飢えて去った（住処のないコボルト、大型の獣など） / returned 冒険者の生還 / home 満腹になって巣へ帰った（ワイバーン） / abandoned 住処を捨てて群れで去った（コボルト） / dispersed 空腹で群れごと出ていった（大ネズミ） |
| events.jsonl | ゲーム内ログに表示される出来事（`{k:番号}` の所に種の名前が入る） |
| stuck.jsonl | `{t, k, id, st, x, y, nopath, web?}`。足踏み：起きて歩く姿（act 1）のまま、ゲーム内の2分（1200 tick）以上ほぼ同じ場所（12px 以内）にいた生き物を、そうなった時点で1回記録する（眠りが半分以上なら数えない）。nopath は、その間に道が見つからないまま歩いていた割合（0.5 以上なら、壁に押しつけて足踏みしていた）。記録はセーブしないので、再開した直後の1200 tick は数え始めからやり直す。web は、その間にクモの巣に捕まっていた割合（0 なら書かない）。分析ツールは、漂う種（ウィスプ、ゴースト）と web が 0.5 以上のものを足踏みとして数えない（tools/analysis/common.ts の countsAsStuck） |
| hitch.jsonl | `{t, t0, k, id, st, x, y, dur, walked, nopath, near, wall}`。短い引っかかり：歩く姿（act 1。巣に捕まっている者と眠っている者を除く）のまま、ゲーム内の3秒（30 tick）で正味半タイル（8px）も進まない状態が続いた区間を、終わった時点で1回記録する（10 tick ごとに見て、2回続けて途切れたら終わり）。止まったままも、行ったり来たりも含む。t は区間を閉じた tick、t0 は始まり（3秒の窓の始まり）、dur は tick 数。walked は区間の間に歩いた道のり（px。24 以上なら往復とみなす）、nopath は道が見つからないまま歩いていた割合、near は始まったときに1.5タイル以内にいた生きている他の生き物の数、wall は始まったときのマスの周り8マスのうち歩けないマスの数。記録はセーブしないので、再開した直後の3秒は数え始めからやり直し、実行の終わりで続いている区間は書かない。分析ツールは漂う種（ウィスプ、ゴースト）を数えない（tools/analysis/common.ts の countsAsStuck） |
| checkpoint.json | ゲームのセーブデータと同じ形式。ブラウザの localStorage（キーは src/save.ts の `KEY`）に入れると、その場面をゲームで開ける |
| snap/dNNN.json.gz | ゲーム内の1日ごとのスナップショット（checkpoint.json と同じ形式を gzip で圧縮）。batch や ab の出力では、meta.json の `snaps` がキャッシュ内の場所を指す |
| meta.json | シード、日数、tick 数、冒険者パーティの上限、実行の来歴 `lineage`（どのバージョンのソースが、どの tick から実行したか）、実行にかかった秒数 |

samples.jsonl は tick が `DAY_TICKS/4` の倍数のときに書く（中断・再開しても同じ tick で書かれる）。
