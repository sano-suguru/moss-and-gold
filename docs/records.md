# 実行ログの形式（runs/<名前>/）

`npm run sim` / `batch` / `ab` が書き出すファイル。どのファイルも、`t` は tick、`k` は種の番号（`src/names.ts`）、`x, y` は px 単位の位置。出力の内容を変えたら、このページと tools/analysis/sim.ts をあわせて直す。

| ファイル | 中身 |
|---|---|
| settle.jsonl | `{t, k, id, ev, how, reason, to, n, x, y}`。群れや個体の出来事。ev ごとの意味は下の一覧 |
| samples.jsonl | ゲーム内の1/4日ごとのサンプル。シードの豊かさ（rich：開いた地表の横穴から歩いて100タイル以内の床1タイルあたりの、食べられる苔とキノコの量）、種ごとの数（`counts`、キーは種の番号）、死骸、開いた床、瓦礫、使える養分とその総量、保存則のずれ（nutrientDrift / goldDrift / rockDrift）、噂、冒険者パーティの数、外の世界の地図の区画数、ドワーフの拠点の発展段階。tick が `DAY_TICKS/4` の倍数のときに書く（中断・再開しても同じ tick で書かれる） |
| deaths.jsonl | `{t, id, k, cause, by, x, y, slain?, near?, camp?}`。cause は死因：eaten 食べられた / fight 戦って倒れた / starve 飢え / burned 焼死 / crushed 崩落 / petrified 石化（by はバジリスクの睨みなら 17、トロールが光の筋を浴びたなら −1）/ killed 襲われた（ゾンビなど）/ dried 干からびた（スライム）/ faded ゴーストが消えた・リビングアーマーのマナが尽きた / planted マイコニドがキノコになった / crumbled スケルトンが崩れた / crumble 眷属が崩れた / sipped ウィスプが大物に吸われた / other。by は手を下した種（なければ −1）。slain は eaten のとき、打ち合いで仕留めてから食べた（1。無ければ一口で食べた）。near は飢え死にした大ネズミだけ、食べられる苔・キノコまでの歩いての距離（60タイルまで、なければ −1）。camp は焚き火で休む一行の冒険者だった（1） |
| births.jsonl | `{t, k, origin, x, y, from?}`。origin は出現の経路：entrance 正面の入口 / mouth 地表の横穴 / fissure 地底の裂け目 / river 川の出口 / shaft 天井の裂け目 / soil 土の養分から / mana マナから / gear 床の武具から（リビングアーマー）/ raised 亡骸が起き上がった（from は亡骸の種）/ born ダンジョンの中で生まれた（親から、卵から） |
| moves.jsonl | `{t, k, n, x, y, tx, ty}`。大ネズミの巣穴の引っ越し：n 匹が (x, y) から (tx, ty) へ |
| exits.jsonl | `{t, k, reason}`。外へ出ていった理由：starving 飢えて去った / returned 冒険者の生還 / home 満腹になって巣へ帰った（ワイバーン）/ abandoned 住処を捨てて群れで去った（コボルト）/ dispersed 空腹で群れごと出ていった（大ネズミ） |
| events.jsonl | ゲーム内ログに表示される出来事（`{k:番号}` の所に種の名前が入る） |
| stuck.jsonl | `{t, k, id, st, x, y, nopath, web?}`。足踏み：起きて歩く姿（act 1）のまま、ゲーム内の2分（1200 tick）以上ほぼ同じ場所（12px 以内）にいた生き物を、そうなった時点で1回記録する（眠りが半分以上なら数えない）。nopath は道が見つからないまま歩いていた割合（0.5 以上なら壁に押しつけていた）、web はクモの巣に捕まっていた割合（0 なら書かない） |
| hitch.jsonl | `{t, t0, k, id, st, x, y, dur, walked, nopath, near, wall}`。短い引っかかり：歩く姿のまま（巣に捕まっている者と眠っている者を除く）、ゲーム内の3秒（30 tick）で正味半タイル（8px）も進まない区間を、終わった時点で1回記録する（10 tick ごとに見て、2回続けて途切れたら終わり。実行の終わりで続いている区間は書かない）。t0 は始まり、dur は tick 数、walked は歩いた道のり（px。24 以上なら往復）、near は始まったときに1.5タイル以内にいた他の生き物の数、wall は周り8マスのうち歩けないマスの数 |
| checkpoint.json | ゲームのセーブデータと同じ形式。ブラウザの localStorage（キーは src/save.ts の `KEY`）に入れると、その場面をゲームで開ける |
| snap/dNNN.json.gz | ゲーム内の1日ごとのスナップショット（checkpoint.json と同じ形式を gzip で圧縮）。batch や ab の出力では、meta.json の `snaps` がキャッシュ内の場所を指す |
| meta.json | シード、日数、tick 数、冒険者パーティの上限、実行の来歴 `lineage`（どのバージョンのソースが、どの tick から実行したか）、実行にかかった秒数 |

stuck と hitch の記録はセーブしないので、再開した直後は数え始めからやり直す。分析ツールは、漂う種（ウィスプ、ゴースト）と、クモの巣に捕まっていたもの（web 0.5 以上）を数えない（`countsAsStuck`）。

## settle.jsonl の ev

**住みか**（k 10 コボルトの住処、12 ゴブリンの集落、14 リザードマンの集落、9 アリの巣。id は住みか）
- found：住みついた。how は soil 土の養分から湧いた / move 引っ越した / split 分かれた。poor が 1 なら、貧しい場所に少ない群れで住みついた
- abandon：捨てた。reason は food 食べ物が尽きた / raids 襲われすぎた / alone 1匹になった / dragon 竜が近くに来た。to は leave 外へ / move 中で移った
- empty：誰もいなくなった
- joined：切り離されていた住みかが、入口側の洞窟とつながった。how は 1 住処のコボルトが内側から掘った / 0 それ以外
- cacheGo（k 12）：蓄えの乏しい集落から、冒険者の物資の置き場へ食料を取りに出た。n は出た数、to は置き場、how は歩いてのマス数
- cacheLoot（k 12）：置き場の木箱をあさって袋に詰めた。n は詰めた量、how は置き場に残った量

**戦**（k 10 コボルト、12 ゴブリン。攻める側の種。id は戦。src/eco/war.ts）
- warGather：蓄えの乏しい群れが、攻めに出るために住みかの前に集まりはじめた。n は出る数、to は攻める住みか
- warGo：集まり終えて攻めに出た。n は出た数、to は攻める住みか
- war：戦が終わった。how は 1 蓄えを奪った / 2 押し返されて退いた / 3 やめて引き返した、n は出た数、lost は倒された数、loot は奪った量。why は how 3 の理由（met<種> その種が近くに来た / hit<種> その種に打たれた / time 着けずに時間切れ / gone 相手の住みかが無くなった / home 自分の住みかが無くなった / none 全員が列を離れた）

**冒険者の一行**（k 25。id は一行）
- enter：入ってきた。how は目標の種類（aim）、q は引き受けた依頼（0 探索、1 宝探し、2 竜退治、3 魔物の狩り、4 アンデッド祓い、5 ゴブリン退治、6 竜の寝床への道探し）、qk は狩る種
- arrive：目標の場所に着いて目当てを見つけた。how は aim、n は目当ての個体、to は目当ての種（竜退治と魔物の狩り）
- wake：焚き火で眠る一行が起こされた。how は watch 見張り / thief 眠りの浅い盗賊 / hit 寝ている者が打たれた / noise 物音。n は気づいた相手の種、doze は見張りがうとうとしていたか、night は夜か
- nightHit：眠っている者への寝込みの一打ち（n は打った種）
- campBreak：夜襲の被害で焚き火を消して発った（how は lost 倒れた者が出た / hurt 深手）
- heroMana：冒険者が倒れた所でマナが立ちのぼった（id は倒れた冒険者、n はマナの量）
- quest（id 0）：町の掲示に依頼が出た。how は依頼の種類、to は狩る種。init が 1 なら、掲示を覚えていない古いセーブから始めて最初に覚えた依頼（ゲーム内ログは出さない）
- calm：依頼を果たした一行の最後の一人が帰り、噂を鎮めた。left は鎮めたあとも同じ依頼が噂から出ているか
- hurtTold：生還者が魔物から受けた被害（石化・死者）を町に伝えた。how はその種、n は件数（一行で種ごとに一度）

**魔物**
- gen：魔物が湧いた（群れごとに1回）。k は種、how は nutr 土の養分 / mana マナ、n は湧いた数
- manaShort：体のマナを全部か無しかで払う種（いまはバジリスク）が、まわりの土からマナを集めきれず、その回は湧かなかった
- manaLow：マナで命をつなぐ大物（トロール・バジリスク・ミノタウロス・ガーゴイル・ヴァンパイア）のマナが尽きかけた
- unbury：壁や瓦礫に埋まっていた生き物が、安全策でいちばん近い床へ出た（x, y は出た先）
- burn：炎に焼かれた。k は火をつけた種（いまはドラゴンだけ）、id は焼かれた個体、n はその種。前に傷を受けてから生き物の更新100回より後の、最初の一回だけ
- web（k 4。id は巣）：クモの巣の出来事。how は catch 捕まった / tear 大きな者が引き裂いた / cut 冒険者が切り払った。by はその者の種
- split（k 5）：スライムが二つに分かれた（n は生まれた個体）
- drag（k 15）：ミノタウロスが獲物の死骸を寝床まで引きずり終えた（n は獲物の種）
- absorb（k 29）：リビングアーマーが武具を取り込んだ。how は floor 床の物 / rob 倒した相手の落とし物、n は武具の種類（ItemKind）
- fall（k 29）：崩れて武具が床に散らばった（n は数）
- gaze（k 17）：バジリスクの睨み。n は相手の種、how は 0 相手が目を背けた / 1 最初に目が合った（ここから石化が進む）/ 2 石像になった。x, y は相手の位置
- patrol（k 17）：縄張りの見回りに出た（x, y は見回り先）
- bedMove（k 17）：寝床を移した。how は 0 見回り先のほうがマナが濃い / 1 襲われて生き延びたあと
- fleeBasilisk（k 2）：大ネズミが見回りのバジリスクから逃げた（生き物の更新20回に1回だけ記録）
- k 19（ヴァンパイア）：scout 従うコウモリが獲物の上を旋回しはじめた / pin 足止めされた獲物に打ちかかった / scatter コウモリの群れにばらけた / reform 姿を戻した / coffinOpened 棺を暴かれた（n は職業）/ lightKill 光の中でばらけられずに倒された / callBats 日暮れにコウモリを呼んだ（n は数）/ raiseFallen 倒れた冒険者に眷属の印を付けた（n は職業）
