### 大ネズミが絶えたシード：seed18

seed18 は地表の横穴が2日目までに開くので、割れ目からの入口がすぐ閉じる。そのうえ、横穴のまわり（道のり18マス）の苔では判定を通ることが少ない（25日で来たのは26匹）。来た大ネズミの多くは大トカゲに食べられ（17）、6日目ごろから0になった。割れ目を序盤だけの入口に戻したことと、入口ごとの判定を18マスにしたことが重なった結果。五巡目では、割れ目から来る大ネズミがこの穴を埋めていた。

## 2. 苔のそばでの飢え死にの原因（優先）

割れ目の決まりを戻したあと、苔のそば（道のり10マス以内）での飢え死にが多かった4シード（abc、seed40、seed18、seed17、20日）で、飢え死にした大ネズミの死ぬ前の約1,000刻み（10刻みごと）を記録して、何をしていたかを分けた。見つけた原因は六つで、全部直した。

| 見つけたこと | 例 | 直し方 |
|---|---|---|
| **出ていく判定と、そのあきらめが毎回ぶつかっていた** | seed40 大ネズミ12：40刻みごとに目当てが消え、近くの苔と巣穴のそばの苔（26マス先）を行ったり来たり | 群れで出ていく判定（`ratDisperse`）は、飢えが7割を越えた者にも働いていたが、出ていく途中で7割を越えたらあきらめる決まりがあるので、次の刻みに出ていくのをやめていた。そのたびに目当ての苔を忘れて選び直していた。7割を越えた者は出ていかない |
| 出ていく判定が、苔を見落としていた | 同上 | 「近くに苔があるか」をいくつかの点を選んで調べていて、まばらな苔を見落としていた。歩いて10マス以内を残らず調べる。着ける口がなくても「出ていく群れ」にしていた（目当てが消える）のもやめる |
| **近くの苔より、遠くの群落を目指していた** | abc 大ネズミ123：10マス先に苔があるのに、87マス先の群落を目指して途中で飢えた | 腹を空かせた者は、歩いて12マス以内でいちばん近い苔かキノコ（立てない深い水のマスは除く）を目当てにする。遠くの群落（土地勘）は、歩いてつながった洞窟の中だけ |
| **届かない目当てを持ち続けていた** | abc 大ネズミ37：道筋のない60マス先の目当てへ、壁に向かって歩き続けた | 道筋が見つからなかったかどうかを、探した直後の4刻みしか見ていなかった。その間ほかのこと（おびえる、休む）をしていると見逃した。目当てへの道筋がないと分かっている限り、あきらめる |
| **向かい合った仲間どうしで押し戻し合っていた** | seed40 大ネズミ679・680：細い通路の苔の手前で、2〜3匹が行ったり来たり | 列の間合い（前の仲間が動いていれば歩みをゆるめる）が、こちらへ向かってくる仲間にも働き、向かい合った二匹が互いにゆるめ合っていた。向きが逆の仲間は、すれ違いとして脇へよける |
| おびえては同じ苔へ戻っていた | seed17 大ネズミ930：苔へ向かう細い通路にゴーストとクモがいて、おびえて逃げては同じ苔へ戻るのを繰り返した | 目当てへ向かう途中でおびえたら、その苔はあきらめて別の苔を探す |

上の4シードで、苔のそばでの飢え死には **48 → 20**（20日）になった。途中で一度、自分の手直しで逆に増えたシードがあった（seed18 で 1 → 59）。いちばん近い苔を選ぶとき、大ネズミが立てない深い水のマスの苔を選んでいたためで、そのマスを除いて直した。

16シードで比べると：

| | 五巡目 | 六巡目 |
|---|---:|---:|
| 飢え死に | 1,085 | 347 |
| そのうち道のり10マス以内に苔があった | 785（72％） | **215（62％）** |

数は4分の1になったが、割合はまだ6割ある。残りの例を見ると、目当ての苔へ向かって歩いている途中に、飢えの限界を迎えている（すでに腹ぺこで、苔まで数マス）ものが多い。このうち今回見つけた種類のもの（行ったり来たり、届かない目当て、押し戻し合い）は、4シードの記録には残っていなかった。苔が薄く（20前後）、一か所に何匹も集まって食べ尽くしている、いわば飢饉のような場面（seed18 の16日目、8匹が一つの巣穴のまわりで）もあり、すべてが動き方の不具合というわけではない。

## 3. ゴブリン：苔とキノコを蓄えの主に

- 集めに出た者（st 4）は、集落のまわり14マス（コボルトの縄張りの外）のキノコと苔を袋（units、20まで）に摘み、いっぱいになったら持ち帰って蓄えにする。キノコを先に摘む。
- 近くに獲物（8マス）がいれば狩り、死骸があれば拾う（足し）。
- 腹を空かせた者は、苔とキノコを腹の7割まで食べる（五巡目の「4割まで」はやめた）。
- 腹の減り方は7割のまま。コボルトの縄張りに入らない決まりも残した。

**蓄えは貯まるようになった。** 五巡目は、蓄えはほとんど0だった（この記録は六巡目から足したので、五巡目の数字はない。前回は集落の様子を追って0が続くのを確かめていた）。中で生まれたゴブリンは 161 → 504。

### オークへの貢ぎ物

| | 五巡目 | 六巡目 |
|---|---:|---:|
| 従えた集落 | 74 | 82 |
| 取り立て（回 / 量） | 13 / 155 | **18 / 961** |
| 飢えて去ったオーク | 287 | 308 |
| 縄張りが続いた日数の中央値 | 0.8 | 0.8 |

「キノコ → ゴブリンの蓄え → オークへの貢ぎ物」の流れは働くようになった（取り立てた量が6倍）。ただ、回数はまだ少なく、オークの縄張りの日数は変わらない。

**途中で見つけて直した不具合（二つ）**：最初に回したとき、蓄えは貯まったのに、取り立ては6回だけだった。調べると、取り立ての時が来ても、縄張りのオークが送られていなかった。

1. 取り立てに行けるのは「腹を空かせていないオーク」に限っていたが、縄張りのオークはたいてい腹ぺこだった。腹ぺこのオークも行けるようにした。
2. それでも送られなかった。取り立ての時には、縄張りのオークはたいてい**飢えて去る途中**（st 9）だった（seed41 では10回中10回）。貢ぎ物は食べ物なので、飢えて去ろうとしているオークも行けるようにし、取り立ては飢えて去るより先に扱う。

残る問題：オークが飢えて去る数は減っていない（308）。オークは1日に約160の食べ物を使うが、取り立ては1回あたり平均50ほど（蓄えの3割）で、1日に1回の間隔では足りない。オークの縄張りが続かない理由は、取り立ての量と間隔よりも、オークの食べ物全体（ゴブリンを食べなくなったあとの穴）にある。取り立ての割合や間隔を変えるか、オークの狩りの獲物を見直すかは、相談したい。

### ゴブリンの集落が続かない理由

| | 五巡目 | 六巡目 |
|---|---:|---:|
| 集落の日数の中央値（すべて / 豊かな上半分） | 1.1 / 1.3 | 1.0 / 1.0 |
| 5日以上続いた集落 | 2 / 52 | 10 / 60 |
| 終わり方：蓄えが尽きた / 襲われた / 1匹 / 皆いなくなった | 14 / 27 / 1 / 23 | 13 / 37 / 0 / 23 |
| 倒した種：冒険者 / オーク / コボルト / そのほか | 194 / 0 / 157 / 126 | 188 / 0 / 133 / 194 |
| 飢え死に | 4 | 40 |

- 5日以上続く集落は増えた（2 → 10）。seed23 は中央値 11.2日、かしたれ・seed41 は最長が10日近い。
- それでも中央値が1日ほどにとどまる理由は二つ：
  - **分かれて新しい集落ができる**：蓄えから子が生まれて15匹を超えると、5匹が新しい集落を作る（23回。五巡目は0回）。新しい集落は、もとの集落から離れた所（30マス以上）に、蓄えなしで始まり、短く終わりやすい。中央値はこの短い集落に引っ張られている。
  - **襲われて終わる**（37）：ゴブリンを倒した種は、冒険者 188、コボルト 133、ドラゴン（焼けた）84、ヴァンパイア 68。オークとの殺し合いは0のまま。
- 飢え死にが 4 → 40 に増えた。数が増えたぶん（中で生まれた 504）、蓄えの尽きる集落が出ている。
