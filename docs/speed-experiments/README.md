# シミュレーションを速くする実験（振る舞いが変わるもの）

検証の道具の作り直し（docs/rework-tools.md）では、展開を1バイトも変えずに大きく速くできる所がなかった（時間の内訳が平ら）。
そこで、**展開が変わってもよい**とした場合にどれだけ速くなり、展開がどれだけ変わるかを試した。**どれもまだ取り入れていない**（パッチとしてここに置くだけ）。

## 試したもの

| | 中身 | パッチ |
|---|---|---|
| A | ウィスプ（光の精を除く）は、生き物の1歩の4回に1回だけ判断して動き、その回に4回ぶん動いて食べる。ほかの回は腹が減るだけ（マナを吸う時機はもとから4回に1回で同じ） | a-wisp.patch |
| B | 苔とキノコの刻みを20刻みごとから40刻みごとにし、一度に2倍進める（増える・枯れる・広がる確率と量、ウィスプとマイコニドの生まれる確率を2倍） | b-moss.patch |
| C | 生き物の1歩を2刻みごとから4刻みごとにし、移動（`tryMove`）・代謝・死骸の腐りを2倍にする。刻みの番号で決まる間隔（来訪、殖える、戦いの間合いなど）は、地上の時間では半分の頻度のまま | c-cr-every4.patch |
| D | 画面なしで回すときの「見たマスの更新」（`lib/engine.ts` の進め方）を20刻みごとから200刻みごとに。見たマスは画面の地図と「初めて見た種」の記録にしか使われない | d-seen.patch |

## 結果

速さ：`npm run bench -- --repeat 3`（seed4、かしたれ、seed7 を、10日目の状態から1日ずつ。3回測って速いほう）。前の版は測るたびに 9.2〜10.7秒と揺れたので、前の版と続けて測った値で比べた。

展開：`npm run ab -- --preset quick`（8シード、前の版の10日目の状態から18日目まで、対にした比較）の31の指標と、`npm run metric` で数えたウィスプ・苔・キノコ・ウィスプ以外の生き物の数（11〜18日目の平均）。

| | 3シード×1日（前の版） | 速くなった割合 | 「はっきり」変わった指標 |
|---|---:|---:|---|
| A ウィスプ | 7.7秒（10.0） | 約2割 | ウィスプ −7％、苔 +0.3％。ほかの31の指標は「ばらつきの内」 |
| B 苔とキノコ | 9.0秒（10.0） | 約1割弱 | なし（31の指標も、ウィスプ・苔・キノコ・生き物の数も「ばらつきの内」） |
| C 生き物の1歩 | 6.3秒（10.0） | 約3割 | 8つ：大ネズミの飢え死に 40→89、巣穴の引っ越し 45→26、ゴブリンの出産 97→29、集落 14→6、オークの来訪 103→52、飢えて去ったオーク 41→20、冒険者に倒されたコボルト 27→10・ゴブリン 39→1。キノコ −0.7％ |
| D 見たマスの更新 | 8.8秒（9.2） | 約4％ | 生き物の展開は変わらない（かしたれ6日で、死・誕生・住みつき・種ごとの数が前の版と同じ）。変わるのは見たマスの地図と「初めて見た種」の記録の時機だけ |
| A＋B | 6.9秒（9.2） | 約2割5分 | ウィスプ −7％、苔 +0.4％、コボルトの来訪 97→148（6対0、ただし差の51％が abc 1シード）。ほかは「ばらつきの内」 |

## 見立て

- **D** は、展開を変えずに数％。ただし `lib/engine.ts` を変えると版が変わり、保存庫の結果はすべて回し直しになる。ゲームの画面は別に `updateSeen` を呼んでいるので、画面には響かない。
- **B** は、効き目は小さいが、展開もほとんど変えない。
- **A** は効き目が大きい（ウィスプが生き物の6割を占めるため）。ウィスプが7％減るのは、食べ方が「2回に1回、1ずつ」から「8回に1回、4ずつ」になり、腹の満ち方が粗くなったためと思われる。気になるなら、食べる量の配り方を調べてから取り入れる。描画では、ウィスプが0.8秒ごとに4倍の幅で跳ぶように見えるおそれがある（画面で見ていない）。
- **C** は展開が大きく変わる。手直しとしては、刻みの番号で決まる間隔（`step % 50` の来訪など）をすべて地上の時間に合わせて直す必要があり、手間も危うさも大きい。

試すときは：`git apply docs/speed-experiments/a-wisp.patch` → `npm test` → `npm run bench` → `npm run ab -- --preset quick`。
